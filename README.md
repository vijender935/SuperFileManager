# 🚀 SuperFileManager

A powerful Python-based File Management Tool built for learning Python, Git, and software development.

---

## 📌 Version

**Current Version:** 3.1

---

## ✨ Features

### 📂 File Information
- File Size
- Image Resolution
- Image Format
- Image Orientation
- Image Mode
- Color Depth
- DPI Detection

### 📁 File Operations
- Rename File
- Copy File
- Move File
- Delete File

### ⚡ Batch Operations
- Batch Rename
- Batch Copy
- Batch Move
- Batch Delete

### 🔍 Search & Filter
- Search Files
- Filter by Extension
- Sort Files
- File Statistics

### 🖼 Image Processing
- Resize Image
- Batch Resize Images
- Convert Image Format
- Batch Image Format Conversion

### 🛡 Safety Features
- Input Validation
- Duplicate Filename Protection
- Logging System

## ▶ How to Run

Clone the repository

```bash
git clone https://github.com/vijender935/SuperFileManager.git
```

Go to project

```bash
cd SuperFileManager
```

Install dependency

```bash
pip install pillow
```

Run

```bash
python src/main.py
```
